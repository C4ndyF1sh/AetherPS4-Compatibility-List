# AetherPS4-Compatibility-List
A compatibility list for AetherPS4, a PS4 for iOS emulator

Playable: Games that can be played without any major issue.
Ingame: Games that can reach gameplay but have game-breaking issues.
(We consider crashes, hangs, graphical issues like texture corruption and vertex explosions, and broken audio as potentially game-breaking issues.)
Menus: Games that can reach the menu but freeze/crash when trying to proceed further.
Boots: Games that show visual or audio output but freeze or crash before reaching the menu.
Nothing: Games that crash when trying to launch or hang on a black screen.
